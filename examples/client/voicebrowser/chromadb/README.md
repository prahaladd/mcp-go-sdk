# ChromaDB Package

A Go package that encapsulates CRUD operations for ChromaDB, providing a clean and simple interface for interacting with ChromaDB collections.

## Features

This package provides the following operations:

### Collection Management
- **CreateCollection**: Create a new collection with metadata, embedding function, and distance function
- **GetCollection**: Retrieve an existing collection
- **ListCollections**: List all available collections
- **DeleteCollection**: Delete a collection by name
- **UpdateCollection**: Update a collection's name and/or metadata

### Document Operations
- **AddDocuments**: Add documents to a collection
- **GetDocuments**: Retrieve documents from a collection with filtering
- **QueryDocuments**: Query for similar documents using semantic search
- **DeleteDocuments**: Delete documents from a collection
- **CountDocuments**: Get the count of documents in a collection

## Usage Example

```go
package main

import (
	"context"
	"fmt"
	"log"

	"chromago/chromadb"
	"github.com/amikos-tech/chroma-go/pkg/embeddings/default_ef"
	"github.com/amikos-tech/chroma-go/types"
)

func main() {
	ctx := context.Background()

	// Create a new client (connects to localhost:8000 by default)
	client, err := chromadb.NewClient(ctx, "")
	if err != nil {
		log.Fatalf("Failed to create client: %v", err)
	}
	defer client.Close()

	// Create an embedding function
	ef, closeEf, err := default_ef.NewDefaultEmbeddingFunction()
	if err != nil {
		log.Fatalf("Failed to create embedding function: %v", err)
	}
	defer closeEf()

	// Create a collection
	collection, err := client.CreateCollection(
		"my-collection",
		map[string]interface{}{"description": "My first collection"},
		ef,
		types.L2,
	)
	if err != nil {
		log.Fatalf("Failed to create collection: %v", err)
	}

	// Add documents
	err = client.AddDocuments(
		collection,
		nil, // embeddings will be generated by the embedding function
		[]map[string]interface{}{
			{"source": "doc1"},
			{"source": "doc2"},
		},
		[]string{
			"This is the first document",
			"This is the second document",
		},
		[]string{"id1", "id2"},
	)
	if err != nil {
		log.Fatalf("Failed to add documents: %v", err)
	}

	// Query documents
	results, err := client.QueryDocuments(
		collection,
		[]string{"first document"},
		5,
		nil,
		nil,
		nil,
	)
	if err != nil {
		log.Fatalf("Failed to query documents: %v", err)
	}
	fmt.Printf("Query results: %+v\n", results)

	// Count documents
	count, err := client.CountDocuments(collection)
	if err != nil {
		log.Fatalf("Failed to count documents: %v", err)
	}
	fmt.Printf("Document count: %d\n", count)

	// Delete documents
	err = client.DeleteDocuments(
		collection,
		[]string{"id1"},
		nil,
		nil,
	)
	if err != nil {
		log.Fatalf("Failed to delete documents: %v", err)
	}

	// Delete collection
	err = client.DeleteCollection("my-collection")
	if err != nil {
		log.Fatalf("Failed to delete collection: %v", err)
	}
}
```

## API Reference

### NewClient
```go
func NewClient(ctx context.Context, basePath string) (*Client, error)
```
Creates a new ChromaDB client. If `basePath` is empty, connects to `localhost:8000`.

### CreateCollection
```go
func (c *Client) CreateCollection(name string, metadata map[string]interface{}, embeddingFunction types.EmbeddingFunction, distanceFunction types.DistanceFunction) (*chroma.Collection, error)
```
Creates a new collection with the specified configuration.

### GetCollection
```go
func (c *Client) GetCollection(name string, embeddingFunction types.EmbeddingFunction) (*chroma.Collection, error)
```
Retrieves an existing collection by name.

### AddDocuments
```go
func (c *Client) AddDocuments(collection *chroma.Collection, embeddings []*types.Embedding, metadatas []map[string]interface{}, documents []string, ids []string) error
```
Adds documents to a collection. Embeddings can be `nil` if the collection has an embedding function.

### QueryDocuments
```go
func (c *Client) QueryDocuments(collection *chroma.Collection, queryTexts []string, nResults int32, where map[string]interface{}, whereDocument map[string]interface{}, include []types.QueryEnum) (*chroma.QueryResults, error)
```
Queries the collection for similar documents.

## Notes

- Make sure ChromaDB server is running before using this client
- The default connection is `localhost:8000`
- Embedding functions are required when creating or getting collections
- All operations use the context provided during client creation
